# Hypotheses 修改假說

此目錄存放尚未進入正式引擎的修改想法。

## 假說狀態

- `OBSERVE`：剛發現，繼續累積。
- `READY_FOR_EXPERIMENT`：樣本與反例足以進入實驗。
- `EXPERIMENTING`：正在比較修改前後。
- `READY_FOR_DECISION`：證據完整，可提交正式討論。
- `REJECTED`：副作用過大或證據不支持。
- `PROMOTED`：已建立 Decision Log 並升級。

## 研究優先度

每個假說以四項評估：

1. 樣本充分度
2. 問題嚴重度
3. 預期改善幅度
4. 修改副作用

優先研究能明顯消除錯誤標籤、且只犧牲少量高品質訊號的假說。
