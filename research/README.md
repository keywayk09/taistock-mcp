# Research 研究中心

此目錄存放尚未進入正式台股引擎的研究資料。

## 原則

- 研究與正式 Engine 分離。
- 每個結論必須能回溯到案例與原始資料。
- 單一案例不得直接修改正式策略。
- 研究必須同時記錄支持案例、反例與副作用。
- 事後漲跌不等於當下可交易，必須保留 `REASONABLE_NO_TRADE`。

## 建議目錄

```text
research/
├── daily/                 # 每日復盤
├── cases/                 # 個別訊號案例
│   ├── correct/
│   ├── missed/
│   ├── wrong/
│   ├── reasonable-no-trade/
│   └── need-more-data/
├── futures/               # 台指期日盤／夜盤復盤
├── trendlines/            # 趨勢線與線型案例
├── hypotheses/            # 修改假說與研究排名
├── experiments/           # 尚未驗證的規則與參數實驗
└── templates/             # 固定格式
```

Git 不保存空資料夾，因此各目錄將在第一筆案例建立時出現。

## 每日研究輸出

每次復盤至少應包含：

1. 當日樣本池與篩選理由
2. 台指期結構與市場背景
3. 代表性的漂亮標籤
4. 不漂亮標籤與原因
5. 漏訊號
6. 錯誤訊號
7. 合理不交易案例
8. MFE、MAE、R 倍數與出場比較
9. 修改假說
10. 尚需累積的樣本與風險

## 升級路徑

```text
研究案例
→ 重複規律
→ 假說
→ 實驗
→ 多市場狀態驗證
→ Decision Log
→ 使用者核准
→ 正式 Engine
```
