## 日期＋「台股」的固定路由（最高優先）

當使用者只輸入日期加上「台股」，例如：

- `8/5 台股`
- `8月5日 台股`
- `2026-08-05 台股`

固定解讀為：**查詢該交易日的簡短資金流入／流出摘要**。

此情況必須：

1. 優先使用官方同日資料與既有法人資金流工具。
2. 不得展開完整盤後報告、長篇大盤分析、夜盤、關鍵價位、權值股逐檔說明或波段評論。
3. 不得先搜尋大量網站後再整理長文。
4. 回答最多保留以下內容：
   - 外資流入／流出金額
   - 投信流入／流出金額
   - 自營商流入／流出金額
   - 三大法人合計流入／流出金額
   - 融資餘額增減（僅當同日資料已公布）
   - 一句結論
5. 若使用者另外明確要求「完整報告、排行榜、前十、卡片、TXT、詳細分析」，才切換完整模式。

固定簡短格式：

```text
M/D 台股資金流入流出

外資：流入／流出 X 億
投信：流入／流出 X 億
自營商：流入／流出 X 億
三大法人合計：流入／流出 X 億
融資餘額：增加／減少 X 億（若已公布）

結論：一句話說明當日主要資金方向。
```

## 固定輸出規格入口

所有「完整資金流入、完整資金流出、法人排行榜、融資融券報告」需求，必須先讀取：

- `docs/FUND_FLOW_FIXED_SPEC.md`

該檔是完整輸出契約。只有使用者明確要求完整報告、排行榜、前十、卡片或 TXT 時才啟用，不得套用到單純「日期＋台股」查詢。

## 完整資金流入／流出交付規格

使用者明確要求完整版本時，固定交付：

- `YYYY-MM-DD 台股資金流入.txt`
- `YYYY-MM-DD 台股資金流出.txt`
- `YYYY-MM-DD 台股融資融券觀察.txt`

固定內容與卡片欄位完全依照 `docs/FUND_FLOW_FIXED_SPEC.md`。

固定原則：

- 同一交易日資料必須同日交付。
- 官方資料未完整取得時，不得拿其他交易日數字冒充。
- 完整模式不得只交法人總額摘要。
- 不得把 HTTP 400 誤判為「沒有資料」。
- 若排行榜介面故障，必須改走上市／上櫃分流抓取後合併排序。
- 上市個股法人資料優先 TWSE。
- 上櫃個股法人資料優先 TPEx。
- 必須保留 requested_date 與 resolved_date；若日期回退，要明確說明。

## 目前最重要事項

- 簡單輸入「日期＋台股」必須快速回覆簡短資金流入／流出，不得再輸出長篇盤後報告。
- 完整模式穩定取得同一交易日的外資與投信個股完整排行。
- 資金流入／資金流出與融資融券依不同公布時間分開產出。
- 完成上市、上櫃分流、合併、排序、失敗回退與驗收測試。

## 驗收標準

1. `8/5 台股` 類型查詢只回簡短資金摘要。
2. 上市、上櫃皆能取得資料。
3. 完整模式可輸出外資與投信買超／賣超前十。
4. requested_date 與 resolved_date 正確。
5. 非交易日可回退最近交易日。
6. HTTP 400、格式錯誤與真正查無資料分開處理。
7. 不混入錯誤日期資料。
8. 完整 TXT 格式可重複產生。
