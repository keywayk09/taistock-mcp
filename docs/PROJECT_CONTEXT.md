## 固定輸出規格入口

所有「資金流入、資金流出、法人排行榜、融資融券」需求，必須先讀取：

- `docs/FUND_FLOW_FIXED_SPEC.md`

該檔是固定輸出契約，優先級高於臨時摘要或模型自行簡化。不得自行合併、縮短或改名。

## 資金流入／流出固定交付規格

使用者要的不是摘要，而是每天固定三份完整檔案：

- `YYYY-MM-DD 台股資金流入.txt`
- `YYYY-MM-DD 台股資金流出.txt`
- `YYYY-MM-DD 台股融資融券觀察.txt`

固定內容與卡片欄位完全依照 `docs/FUND_FLOW_FIXED_SPEC.md`。

固定原則：

- 同一交易日資料必須同日交付。
- 官方資料未完整取得時，不得拿其他交易日數字冒充。
- 不得只交法人總額摘要。
- 不得把 HTTP 400 誤判為「沒有資料」。
- 若排行榜介面故障，必須改走上市／上櫃分流抓取後合併排序。
- 上市個股法人資料優先 TWSE。
- 上櫃個股法人資料優先 TPEx。
- 必須保留 requested_date 與 resolved_date；若日期回退，要明確說明。

## 驗收標準

1. 上市、上櫃皆能取得資料。
2. 可輸出外資與投信買超／賣超前十。
3. requested_date 與 resolved_date 正確。
4. 非交易日可回退最近交易日。
5. HTTP 400、格式錯誤與真正查無資料分開處理。
6. 不混入錯誤日期資料。
7. 三份 TXT 格式完整且可重複產生。
8. 每次產出前必須依 `docs/FUND_FLOW_FIXED_SPEC.md` 的驗收清單逐項檢查。
