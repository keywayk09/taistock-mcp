# Knowledge 知識庫

此目錄只存放經過足夠案例驗證、可以重複使用的研究結論。

## 與 Research 的差別

- `research/`：案例、假說、反例、未完成實驗。
- `knowledge/`：已驗證、可追溯、可以轉為正式規格的結論。

## 每份知識文件必須包含

1. 適用策略或型態
2. 定義
3. 支持樣本數
4. 反例數
5. 適用市場狀態
6. 不適用市場狀態
7. 成功率、PF、MFE、MAE 等證據
8. 已知副作用
9. 對應 Research Case／Hypothesis／Decision ID
10. 最後驗證日期

## 升級門檻

研究結論進入 Knowledge 前，至少必須：

- 不只來自單一交易日
- 同時保留支持案例與反例
- 跨不同盤勢驗證
- 清楚說明修改副作用
- 可由原始資料重現
- 經使用者核准
